### 架构说明
本目录实现双视图一体化的交互式知识图谱 Web 查看器：
1. 3D 知识星云漫游主视图（`index.html`）：100% 官方原生复刻，正四面中空薄壳与 33.4% 边棱聚拢算法，中英双语与多数据源切换；
2. 2D 拓扑大纲与诊断工作台（`tree.html`）：深度逆向 `math.pansgo.com` 打造的高级暗黑玻璃拟态第二视图，包含先修链递归树（硬/软先修徽章与先修理由 why）、DAG 最长路径分层、掌握标准清单与核心诊断题测评系统。
双视图支持 URL Hash（如 `#cnm_001`）双向实时联动与一键无缝跳转。

### 文件列表与功能说明
| 文件名 | 地位 | 功能 |
|---|---|---|
| `index.html` | 3D 星云主视图入口 | 100% 像素级复刻官方 3D 交互、集成多数据源切换器、思源宋体/Newsreader 高级字体、双视图切换胶囊与防遮挡左边栏布局的图谱主页 |
| `tree.html` | 2D 拓扑诊断工作台入口 | 像素级对齐参考的高性能拓扑大纲，全面支持 Marble 国际微知识点（1590 节点）、中国初中数学（333 节点）与联合图谱（1923 节点）自由切换，具备深浅双主题、多维过滤器自适应、树状先修链递归展开、拓扑最长路径分层、掌握标准与核心诊断题测评 |
| `graphdata-marble.json` | 官方原始烘焙数据 | 提取自官网的 1590 个国际小学微知识点 3D 倒圆锥坐标与 3221 条先修依赖边 |
| `graphdata-cn-math.json` | 初中数学有机坐标 | 经过 220 轮 3D 物理力导向退火仿真、彻底消除垂直柱子共线的 333 个初中数学微知识点原生坐标 |
| `graphdata-union.json` | 全量联合图谱数据 | 融合 Marble 基础底座与中国初中数学顶层穹顶的 1923 节点全量 3D 知识星云图谱 |
| `i18n-data.json` | 国际化双语字典 | 包含 8 大学科、54 个细分领域、1590 个微知识点中英映射及界面 UI 词条 |
| `official-style.css` | 官方样式资产 | 提取自官网的全部 CSS 样式、Base64 字体定义与响应式排版 |
| `graph3d.js` | 备用 WebGL 引擎 | 基于 Three.js 实现的 3D 倒圆锥渲染器（备用模式） |
| `graph.js` | 备用 2D 拓扑引擎 | 基于 HTML5 Canvas 的平面力导向拓扑引擎（备用模式） |
| `graphdata.json` | 默认启动图谱数据 | 默认由 Marble 官方全量数据软链接或烘焙的本地运行时核心 3D 数据文件 |
| `official-body.html` | 官方骨架模板 | 从官网逆向提取的 HTML DOM 结构模板，供静态构建器注入渲染 |
| `style.css` | 自定义补充样式 | 备用视图与高质感毛玻璃面板扩展样式表 |
| `libs/` | 本地基础图形库 | 包含离线 `three.min.js` 与 `OrbitControls.js` |
