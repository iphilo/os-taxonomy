# CN Math Taxonomy source

## Scope

This directory preserves the data imported from `xiaoyang111222/cn-math-taxonomy` at commit `e47d9d1330a319b55ce7755792f75c45b3849330`. It supplies Chinese junior-high mathematics topics, prerequisite edges, questions, verification artifacts, and Chinese curriculum-standard mappings.

## Contents

- `data/topics.json`: 333 source topics.
- `data/dependencies.json`: 616 source prerequisite edges.
- `data/questions.json`: 1,407 diagnostic questions.
- `data/cn-curriculum-standards.json`: the source's curriculum mapping data.
- `LICENSE`: upstream CC BY-NC 4.0 license, retained without modification.

The files in `data/` are source copies. Do not change them when adding application-specific metadata; add that metadata to the union layer instead.
